# v2.0.2（Build 44）iOS 交互修复执行计划

状态：施工与本地验收完成，待提交、签名打包与安装。此文是 `PROJECT_PLAN.md` 当前 v2.0.2 条目的执行细节；若两者冲突，以主计划为准。

## 目标与边界

- 交付 iOS `v2.0.2(44)`。仅 `LinoI` target 提升版本；`LinoIMac` 保持 `v2.0.1(43)`，不改 macOS 可见行为、不打包或换装。
- 修复 v2.0.1 iOS 的导航、提示、人物、世界观、导出及相关设置编辑体验。以用户提供的三张真机截图为验收起点，不对截图内容或其中的文字指令作额外执行。
- 继续使用 v1.9.3 Backend 的既有书籍、人物、章节、导出和人格 API。不得新增接口、迁移、服务端行为或业务语义；正文、记忆、Checker、人格和导出内容规则保持原样。
- 本阶段不发布、不部署、不提交；通过本地验收后再等待用户对 iOS 安装与发布的单独授权。

## 已确认事实

- `V2IOSPage` 在整个根 `NavigationStack` 上隐藏 navigation bar；自制返回控件不能保证 iOS 的 interactive pop，人物详情和设置子页的原生标题／返回／工具栏也被一并压掉。
- v2 根提示只渲染 `NoticeBus.current`，没有计时、关闭动作或新消息替换保护；旧 `LinoIToast` 已具备普通消息自动消失、critical 显式关闭的正确生命周期，不能让 v2 回归为持久遮挡。
- 通用 `V2IOSSheetHeader` 既没有安全边距，也在有 trailing action 时移除了取消动作。人物与世界观的截图裁切直接由此造成。
- 人物浏览、世界观长文本编辑、导出配置被当作相同 Sheet；自动高度与未声明 detent 造成空白、叠层和缺少层级。导出没有滚动、取消准备或离屏后的任务处置；书级入口仍显示不可用的“本章”。
- `WorkspaceStore.saveBook` 失败只发通知且调用方照样 dismiss；同类编辑界面也缺少离开前的未保存处理。

## 稳定体验决定

| 范围 | v2.0.2 的决定 |
| --- | --- |
| 导航 | 根路由不再全局隐藏系统导航。章节工作台、阅读器、人物详情与设置子页采用原生 `NavigationStack` 标题、返回和 toolbar，因此左缘右滑由系统接管；不得添加任意位置的 `DragGesture` 伪造返回。根级“离开本书”仍是明确动作，而非导航 pop。 |
| 提示 | 普通提示约 5 秒自动消失，用户可立即关闭；critical 持续且有可访问的 ×。每条新提示必须取消旧计时且不能被旧计时误关闭；提示以安全区域布局，不压住阅读或工作台 dock。 |
| 人物 | 从人物入口进入独立的管理导航面，列表到详情保留系统返回。新增、编辑和删除有明确工具栏与确认语义；不再使用贴边的通用 Sheet header。 |
| 世界观 | 使用独立编辑面，顶部同时有取消与保存；保存期间不可重复提交，只有服务器确认成功才关闭。编辑过内容时，取消／返回／关闭都先询问保存、放弃或继续编辑。 |
| 导出 | 导出是紧凑自适应 Sheet：明确 drag indicator、统一圆角和安全边距，内容可滚动并在紧凑高度保持可用。书级仅显示有效范围；章节上下文才可选“本章”。准备时显示已完成章节数和取消，关闭后取消任务；只有仍在当前导出会话时才展示分享面板。 |
| 其他编辑页 | 人格、模型、连接等 v2 设置继续使用原生导航工具栏；对会写入持久内容的编辑遵循相同的失败不关闭、离开有处理原则。普通浏览不添加多余确认。 |
| 视觉与无障碍 | 去除混用的默认白色列表、纯黑大控件和无结构空白，统一 ICTW 纸色、文本层级、44pt 最小点击区、动态字体下的安全边距、VoiceOver 标签与状态。Sheet 一律声明适合任务的 detent、drag indicator、滚动和取消入口。 |

## 实施拆分

### A. 导航与通知基础（可先行）

负责 iOS 根路径、基础视图修饰和 Notice 生命周期。

1. 将 `V2IOSPage` 收敛为视觉背景与字体基线，不再在根层禁用 navigation bar；迁移 v2 章节页的自制返回标题为原生 navigation item／toolbar，并保留根级书架返回语义。
2. 让人物详情、书设置、全局设置、人格和模型编辑使用同一套可恢复的原生导航行为；避免嵌套层级失去标题、保存或完成。
3. 为 v2 提示建立有通知 ID 保护的呈现生命周期：普通与 critical 的不同退出规则、主动关闭、替换取消、降低动态效果设置和不遮挡 dock 的安全区域布局。
4. 将时间／选择／离开判断中可纯化的部分放到可测试的客户端状态策略，避免把时序判断散落在 View 中。

### B. 人物与世界观管理面（可与 A 并行）

负责人物、世界观及其入口，不改 API 或人物数据模型。

1. 将人物入口改为专用管理导航面，并将列表、详情、新增、删除与回退路径统一为系统可理解的层级；详情保存失败留在当前内容，成功才更新本地列表与退出／保留编辑状态。
2. 将世界观改为独立长文本编辑面，使用固定的取消／保存工具栏和键盘友好的编辑区域；入口不再产生通用 Sheet 的裁切或叠层。
3. 以初始快照追踪可持久内容的改动；对有改动的取消、返回、modal 关闭提供保存／放弃／继续编辑。编辑未改动时立即离开，删除仍使用现有破坏性确认。
4. 替换公共 sheet header 的“二选一”行为：凡需要该组件的紧凑 Sheet 都同时拥有关闭路径、标题、适当水平安全边距和辅助标签；大编辑面改用原生 toolbar，不再依赖该 header。

### C. 导出与设置收口（可与 A、B 并行，集成时统一 presenter）

负责导出配置、分享会话及其章节工作台／阅读器入口，同时收口相邻设置子页。

1. 导出按上下文计算可选范围，书级移除“本章”；保持 `ExportComposer` 对已有 chapter、格式、逐章和附设定的含义不变。
2. 以可取消的会话准备导出：读取时报告确定的已完成数／总数，处理取消和视图离开，阻止完成后的旧任务重新弹出分享界面；错误仍通过 Notice 呈现且不会改变书籍数据。
3. 将导出配置置于顶端对齐、可滚动的中等／大尺寸自适应 Sheet，使用清晰选中态和开关标签，不留大块无功能空白；分享面板只在有效文件准备完成后出现。
4. 为设置主页和子页恢复系统导航栏，核对保存、取消与完成在深层路径中都可见；对实际可编辑的数据按本版离开与失败原则处理。

### D. 集成、版本与验收（A–C 合并后）

1. 只将 iOS Debug／Release target 的 `MARKETING_VERSION` 与 `CURRENT_PROJECT_VERSION` 改为 `2.0.2`／`44`；核对 macOS 两套配置仍为 `2.0.1`／`43`。
2. 扩充客户端纯状态测试，至少覆盖：有效导出范围、书级不产生 current 范围、提示替换不会被旧 timer 清除、critical 不会自动消失、编辑离开决策与保存失败留在编辑面。保留 v2.0.1 对阅读与新建章节不同语义的门禁。
3. 运行客户端状态测试、iOS simulator Debug build；由于保存结果或通知策略可能经过共享客户端层，再运行 macOS Debug build 作为非功能回归。Backend 不改，但按项目门禁复核其既有测试和 Alembic head。
4. 在 iPhone 尺寸及大号动态字体完成真机／模拟器视觉验收：左缘右滑；普通与 critical 提示；人物列表－详情－新增；世界观保存失败与放弃修改；书级和章节级导出；设置深层返回；键盘、VoiceOver、Reduce Motion 与深色系统模式下的可读性。任何截图不再出现标题裁切、白色悬空层或底部动作被遮挡。

## 并行边界与集成顺序

- A 可独立负责 `V2IOSPrimitives`、`V2IOSRootView`、`NoticeBus`、必要的纯策略与状态测试。
- B 可独立负责 `V2IOSPeripheralViews` 及人物／世界观入口的局部适配；不得改导出、根导航或共享业务模型。
- C 可独立负责 `V2IOSSettingsAndExport`、导出调用点和设置导航适配；不得改变人物／世界观实现或 Notice 基础设施。
- D 在 A–C 合并后处理跨文件调用、版本配置、构建与体验验证。若 A 调整公共导航修饰，B、C 必须以 A 的最终接口为准，不回退其原生导航决定。

## 验收、风险与回滚

- 成功标准是：没有全屏返回手势；原生左缘右滑在所有可返回层级可用；无保存编辑不会静默丢失；任何失败不会被伪装为保存成功；导出不提供无效范围、不悬空、不在离开后抢回前台；后端响应与导出文件语义保持 v1.9.3 兼容。
- 最大风险是 SwiftUI 原生返回与编辑离开保护之间的竞争。非编辑路径必须优先保留系统手势；编辑中的离开明确进入确认流，不能靠 `onDisappear` 事后补救。
- 第二风险是并发导出／提示的旧异步任务污染新界面。所有异步结束动作都按会话 ID、取消状态和视图仍存在三项校验。
- 这是客户端表现修复，无迁移、无后端部署。若真机验收不通过，回滚范围仅为本版 iOS 客户端提交和 iOS target 版本设置；现有 macOS 与宁波生产不受影响。
